# Support

This is pre-alpha open-source software with no production support commitment.

- Use GitHub Issues for reproducible bugs and contract proposals.
- Use GitHub Discussions for integration questions once Discussions are enabled.
- Use GitHub Security Advisories for vulnerabilities; never disclose them in public issues.

Include the commit/version, Python and OpenTelemetry versions, a synthetic reproducer, and the expected invariant. Do not attach real prompts, source code, credentials, personal data, or production telemetry.
